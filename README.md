# E-commerce Vue.js

Atividade prática da trilha Fullstack aplicando os conceitos de:

- Vue.js com Options API
- TypeScript sem uso de `any`
- Componentização com Props e Emits
- Reatividade com `data()`, `computed` e `methods`

## Funcionalidades

- Listagem de produtos com componente `ProductCard`
- Carrinho com adição e remoção de itens
- Cálculo automático de total de itens e preço final

## Tecnologias

- Vue.js 3
- TypeScript
- Vite

## Como rodar

```bash
npm install
npm run dev
